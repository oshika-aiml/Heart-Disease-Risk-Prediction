# Heart Disease Risk Prediction

Logistic Regression model on the UCI Heart Disease (Cleveland) dataset.

## Features used
age, cholesterol, resting blood pressure, max heart rate

## Result
Test accuracy: 78.33%


## How to run

**Option 1: Google Colab (easiest)**
1. Open https://colab.research.google.com
2. Create a new notebook
3. Copy the code from `heart_disease_prediction.py` and paste it into a cell
4. Click Run

**Option 2: On your computer**
1. Install requirements: `pip install -r requirements.txt`
2. Run: `python heart_disease_prediction.py`


## Tools used
Python, pandas, scikit-learn (developed in Google Colab)


## Note
This is a learning project, not a medical tool.
